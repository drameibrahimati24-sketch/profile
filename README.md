# Drame Ibrahima — Portfolio

A responsive AI engineering portfolio built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Personalize

Edit the `profile`, `skillGroups`, and `projects` values near the top of `src/App.tsx`. Replace the study-date, email, social profile, and project-link placeholders with your own details. The contact form opens a prefilled email draft; this site does not send or store messages.

The theme toggle saves the selected theme in local storage and otherwise follows the visitor's system preference.
